# Psyche Horoscope - Landing Page

Landing page for [psychehoroscope.com](https://psychehoroscope.com).

## Deploy to GitHub Pages

1. Create a new repo on GitHub (e.g. `psychehoroscope/landing`)
2. Push this folder:

```bash
cd landing-page
git init
git add .
git commit -m "Initial landing page"
git branch -M main
git remote add origin git@github.com:YOUR_USERNAME/landing.git
git push -u origin main
```

3. Go to repo Settings > Pages > Source: **Deploy from branch** > `main` > `/ (root)` > Save
4. Page will be live at `https://YOUR_USERNAME.github.io/landing/`

## Custom Domain (optional)

Add a `CNAME` file with your domain and configure DNS.
